1. Mục tiêu tổng thể

  • Bộ Office Web (Docs + Sheets + Slides) tương tự Google Workspace.
  • Backend: NestJS + Microservices từ đầu.
  • Web = Cloud-first · Desktop (Tauri) = Offline-first + tùy chọn sync Cloud.
  • Mobile ngắn hạn: PWA · Dài hạn: React Native.
  • Có AI hỗ trợ code → effort giảm rõ rệt so với code thuần.

2. Chiến lược dữ liệu theo nền tảng

Nền tảng Chiến lược Ghi chú
Web Cloud-first PostgreSQL + S3. IndexedDB chỉ cache.
Desktop (Tauri) Offline-first SQLite là nguồn chân lý. Sync Cloud tùy chọn.
Mobile PWA Cloud-oriented Ngắn hạn.
React Native Có thể Offline-first Dài hạn, viết lại UI.

Mỗi service là một NestJS app độc lập. Frontend chỉ gọi qua API Gateway. Bắt đầu với ít service.

4. Danh sách Service

Khởi đầu: api-gateway · auth-service · file-service · docs-service

Thêm dần: sheets-service · slides-service · ai-service · sync-service · collaboration-service

5. Tech Stack

Web: React 19 + Vite 6 + TypeScript + Tailwind + TipTap + Univer + PWA

Desktop: Tauri 2.0 + SQLite (Offline-first)

Mobile: PWA (ngắn hạn) → React Native (dài hạn)

Backend: NestJS Microservices + NATS + PostgreSQL + Redis + S3 iNET

DevOps: Docker → Kubernetes + GitHub Actions + OpenTelemetry

6. Lộ trình triển khai

Giai đoạn 0 — Chuẩn bị (1.5–2.5 tuần)

Monorepo, NestJS services cơ bản, Docker Compose, Vite + React, CI/CD, tách docx-engine.

Giai đoạn 1 — Core Services (3–5 tuần)

Auth + File Service (pre-signed S3) + API Gateway. Dashboard Cloud-first.

Giai đoạn 2 — Docs Service (6–10 tuần)

docs-service + TipTap + auto-save Cloud + tính năng cơ bản.

Giai đoạn 3 — Sheets Service (8–12 tuần)

sheets-service + Univer + formula + chart. Scale độc lập.

Giai đoạn 4 — Slides + Suite (5–8 tuần)

slides-service, Dashboard chung, theme, PWA.

Giai đoạn 5 — AI Service (4–7 tuần)

ai-service + queue job + scale worker.

Giai đoạn 6 — Desktop Tauri Offline-first (5–8 tuần)

Tauri 2.0 + SQLite, làm việc offline, tùy chọn sync Cloud.

Giai đoạn 7 — Sync Service (4–7 tuần)

Đồng bộ 2 chiều Desktop ↔ Cloud + conflict resolution.

Giai đoạn 8 — Realtime Collaboration (sau)

Yjs / PartyKit / Liveblocks.

Giai đoạn 9 — Mobile Native React Native

Viết lại UI/UX. Effort +3–6 tháng (có AI hỗ trợ).

7. Thứ tự ưu tiên tính năng

Must-have (MVP) Docs + Sheets Web (Cloud-first) · Auth · File manager · Pre-signed S3 · Auto-save

Should-have Slides · Version history · PWA · Desktop Tauri Offline-first · Export PDF

Nice-to-have / Dài hạn Sync Desktop↔Cloud · Realtime · AI agent · React Native · Template

10. Checklist khi bắt đầu

  • Setup monorepo (Turborepo + pnpm)
  • Tạo api-gateway, auth-service, file-service (NestJS)
  • Docker Compose (PostgreSQL, Redis, NATS)
  • Khởi tạo Frontend Vite + React
  • Pre-signed URL S3 hoạt động
  • Làm Docs Service + TipTap (Cloud-first)
  • Sau đó đến Sheets Service
  • Thiết kế API versioning + logging + tracing
  • Khi Web ổn → tích hợp Tauri Desktop (Offline-first)
  • Mobile native (React Native) để giai đoạn dài hạn
